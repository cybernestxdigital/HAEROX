# Build a Premium HAEROX Agency Website

Create a **premium, modern, visually impressive business/creative agency website for HAEROX**.

The website will ultimately be hosted on:

**https://haerox.com**

The website must be designed to look like a **high-end global creative/digital agency**, with strong visual presentation, premium typography, large imagery, smooth animations, excellent spacing, and a sophisticated black-and-white brand identity.

## 1. IMPORTANT TECHNOLOGY REQUIREMENT

Build the website using:

* HTML5
* CSS3
* Vanilla JavaScript

Do NOT use:

* React
* Next.js
* Node.js backend
* PHP
* Database
* Authentication
* Admin dashboard
* CMS
* Login system

The final project must be completely compatible with **standard Hostinger web hosting**.

It should work simply by uploading the website files to:

`public_html`

The website must NOT require a running server.

Brand name:

**HAEROX**

Use the provided HAEROX logo as the primary website logo.
