IMPORTANT TECHNOLOGY RULE:

For this entire website project, use ONLY:

* HTML5
* CSS3
* Vanilla JavaScript

DO NOT use React.
DO NOT use Next.js.
DO NOT use Vue.
DO NOT use Angular.
DO NOT use Vite.
DO NOT use Node.js.
DO NOT use Express.
DO NOT use TypeScript.
DO NOT use any frontend framework.
DO NOT create a backend.
DO NOT create a database.
DO NOT create an admin panel.
DO NOT create authentication or login.

The website must be a completely static HTML/CSS/JavaScript website with JavaScript-powered interactions and animations.

HOSTING REQUIREMENT:

The final website must be directly compatible with Hostinger shared hosting.

The website must work by uploading the project files directly into:

public_html/

The root of the project MUST contain:

index.html

Use separate HTML files for separate pages, for example:

index.html
services.html
portfolio.html
about.html
contact.html

Use a clean structure:

/
├── index.html
├── services.html
├── portfolio.html
├── about.html
├── contact.html
├── css/
│   └── style.css
├── js/
│   └── script.js
├── images/
│   ├── logo/
│   ├── hero/
│   ├── services/
│   ├── portfolio/
│   └── about/
└── favicon.ico

IMPORTANT PATH RULE:

Use only relative paths.

Correct:

./css/style.css
./js/script.js
./images/logo/logo.png
./services.html

Do NOT use:

/src/
/client/
/app/
/localhost/
/replit-specific paths/

Do NOT depend on a development server.

Do NOT require npm start.

Do NOT require a Node.js server.

Do NOT require a build command to make the website work.

The files inside the project must already be production-ready static files.

The website must work directly by opening:

index.html

and after uploading to:

public_html/

it must work directly on the Hostinger domain.

GITHUB REQUIREMENT:

Keep the repository clean and deployment-ready.

The GitHub repository root must contain index.html.

Do not put the actual website inside another nested folder.

Correct:

GitHub Repository
├── index.html
├── services.html
├── css/
├── js/
└── images/

Incorrect:

GitHub Repository
└── project/
└── index.html
